# lane-agent Monorepo 重构实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 lane-agent 与 lane-serve 合并为一个 bun workspaces monorepo（apps/desktop、apps/web、apps/mobile、apps/server + packages/protocol），保持构建、打包、部署行为不变。

**Architecture:** 原 lane-agent 拆成 Electron 主进程（apps/desktop）与 Vite 渲染端（apps/web，`src/core` 随之整体迁移）；lane-serve 的 web/ 与 server/ 原样拷入 apps/mobile、apps/server；新建纯 ESM 的 packages/protocol 供 web/mobile 共享手机同步协议。根目录只保留 workspaces、脚本和文档。

**Tech Stack:** bun workspaces、Vite 8、React 19、Electron 45 + electron-builder、TanStack Start、Express 5 + Socket.IO。

**Spec:** `docs/superpowers/specs/2026-11-24-monorepo-design.md`

## Global Constraints

- 分支：`refactor/monorepo`（已创建，所有提交在此分支）。
- 包管理：根目录 bun；`apps/server/package-lock.json` 保留，其余子包不保留 lockfile。
- 不改线上路径：nginx root 仍是 `/opt/lane-serve/web/dist/client`；server 仍部署 `/opt/lane-serve/server`、端口 6060。
- apps/server 不依赖 `@lane/protocol`，事件名与校验保留在 server 内。
- 注释和 UI 文案用中文；Prettier（单引号、100 列、ES5 trailing comma）。
- 没有测试框架：每个任务的验证 = tsc / vite build / 服务实际启动 + curl / Playwright 检查。
- 每个任务结束提交一次，提交信息末尾带：
  `Co-Authored-By: Claude Code <noreply@anthropic.com>`

## File Structure（目标）

```
apps/desktop/        src/（原 src/app）、tsconfig.json、assets/{icon.png,agent-desktop-skill/}、resources/opencode-cli/、scripts/bundle-*.mjs
apps/web/            src/{web,core,assets}、vite.config.ts、tsconfig.json
apps/mobile/         lane-serve/web 全量（src、public、vite.config.ts、tsconfig.json、tsr.config.json、upload.sh）
apps/server/         lane-serve/server 全量（src、upload.sh、package.json、package-lock.json）
packages/protocol/   index.js、index.d.ts、package.json
package.json         根 workspaces + 转发脚本
```

## Review Focus

- **desktop 渲染产物路径**：`build:renderer` 把 `apps/web/dist` 拷到 `apps/desktop/dist` 后，`main.ts` 的 `new URL('../dist', import.meta.url)` 仍能找到页面；验证 = Task 2 的 electron:dev / start。
- **electron-builder 依赖打包**：`@opencode/client` 被提升到根 node_modules 后仍须进安装包；验证 = Task 2 的 `electron:package` 至少跑通 macOS 产物并检查 app.asar 含该依赖。
- **workspace 包解析**：`@lane/protocol` 必须同时被 Vite 构建和 tsc 解析；验证 = Task 5 的 tsc + build。
- **部署 tarball 内容**：mobile 含源码和 dist、server 含 src 和 package-lock；验证 = Task 6 的 tar 列表检查。
- **端口与代理**：web 5173、mobile 3000、server 6060，mobile 的 `/api`、`/socket.io` 代理保持；验证 = Task 3/4 的启动检查。

- [ ] **Step 2: 新建 `apps/desktop/package.json`**

- `name: lane-desktop`、`private: true`、`type: module`、`main: dist-electron/main.js`
- scripts：
  - `build`: `tsc -p tsconfig.json`
  - `build:renderer`: `bun --cwd ../web run build && rm -rf dist && cp -R ../web/dist dist`
  - `dev`: `tsc -p tsconfig.json && (bun --cwd ../web run dev & VITE_PID=$!; trap 'kill $VITE_PID' EXIT; electron . --dev)`
  - `start`: `bun run build:renderer && tsc -p tsconfig.json && electron .`

- dependencies：`@opencode/client`；devDependencies：`electron`、`electron-builder`、`typescript`、`@types/node`、`agent-desktop`、`npm`（版本照抄根 package.json）。

- [ ] **Step 3: 修模块路径解析**

- `scripts/bundle-runtime.mjs`：用 `import { createRequire } from 'node:module'` + `createRequire(import.meta.url).resolve('npm/package.json')` / `resolve('agent-desktop/package.json')` 得到包目录再 `cp`，不再写死 `node_modules/...`。
- `src/skill.ts` 的 `roots()` 开发态：`pkg` 改为 `dirname(require.resolve('agent-desktop/package.json'))`；`skill` 保持 `join(base, 'assets', 'agent-desktop-skill')`。
- `scripts/bundle-opencode-cli.mjs` 的 `.cache/opencode-cli` 保持相对 cwd（= apps/desktop）。

- [ ] **Step 4: 根 package.json 清理**

删除已迁走的 renderer/desktop 依赖与全部 electron/vite 脚本；根 scripts 增加 `electron:dev`、`electron:start`、`electron:package`、`electron:package:linux`、`electron:package:win`、`bundle:cli`、`bundle:runtime`，均转发 `bun --cwd apps/desktop run <script>`。
