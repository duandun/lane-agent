## Commands

本 app 是 lane-agent monorepo 的 workspace，依赖和锁文件都在仓库根目录。

```bash
# 仓库根目录
bun install
bun run dev:welcome   # Vite dev server on http://localhost:3001
bun run build:welcome # production build (Nitro output)

# apps/welcome 目录
bun run dev     # 3001
bun run build   # production build (Nitro output)
bun run lint    # eslint
bun run format  # prettier --write + eslint --fix
bun run check   # prettier --check (does not typecheck)
bunx tsc --noEmit  # typecheck — the only way to check types, no script for it
```

There is no test framework or test runner configured. Do not assume `npm test` exists.

Install dependencies with bun from the repository root (`bun.lock` is authoritative). shadcn components:

```bash
npx shadcn@latest add <component>
```

## Architecture

TanStack Start app on React 19, Vite 8, file-based TanStack Router, Tailwind CSS v4, deployed to Vercel via Nitro. `vercel.json` pins framework detection to `tanstack-start`; `vite.config.ts` plugin order is `devtools → nitro → tailwindcss → tanstackStart → viteReact` — keep it.

**Router wiring:** `src/router.tsx` exports `getRouter()`, which creates the router from the generated `routeTree` with `scrollRestoration` and intent preloading. There is no TanStack Query integration or router context — the landing page is static apart from the theme menu.

**SSR document shell:** `src/routes/__root.tsx` uses `shellComponent` (not `component`) to render `<html>`/`<head>` via `HeadContent` and `<Scripts />`. Global CSS is imported as a URL (`../styles.css?url`) and injected through the route's `head().links`. The self-hosted Manrope font is preloaded there; the router devtools panel is mounted in the root shell.

**Routing:** routes are files in `src/routes/`. `src/routeTree.gen.ts` is generated by the router plugin — never edit it by hand. API routes use the `server.handlers` option on `createFileRoute`; server-only logic uses `createServerFn` from `@tanstack/react-start`.

**Styling:** Tailwind v4, CSS-first — there is no `tailwind.config.js`. Tokens live in `src/styles.css`: the Lane blue palette in `:root` plus shadcn tokens in `@theme inline`, with `.dark` overrides. Fonts are self-hosted (`public/fonts`), not fetched from Google. Add new design tokens there, not in a config file. Dark mode is class-based (`@custom-variant dark`).

**Aliases:** both `#/*` and `@/*` resolve to `src/*` (tsconfig, Vite `resolve.tsconfigPaths`, and `package.json#imports`). Prefer the `#/` form used by `components.json`: components → `#/components`, UI primitives → `#/components/ui`, utils → `#/lib/utils` (`cn` helper).

## Conventions

- Prettier: single quotes, 100 columns, ES5 trailing commas. ESLint extends `@tanstack/eslint-config` with import-order and array-type rules disabled.
- shadcn config: style `new-york`, base color `zinc`, lucide icons, CSS variables enabled.
